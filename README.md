# Mudit Kumawat — Manga-Inspired Portfolio ⚡

## 🎨 Visual Direction & Design

- **Manga Aesthetic**: Ink black (`#09090b`), warm paper white (`#f4f1ea`), high-contrast grayscale, and vibrant crimson accents (`#e63946`).
- **Anime Opening Ambient Effects**: Dynamic layered background featuring drifting ink flecks, softly glowing crimson energy particles, and speed lines.
- **Micro-Interactions & 3D Tilt**: Card hover micro-tilts, interactive sound toggle, scroll progress indicators, and smooth panel reveals.
- **Accessibility**: Comprehensive `prefers-reduced-motion` compliance to adapt for user preferences without sacrificing layout or readability.

## 🛠️ Tech Stack

- **HTML5**: Semantic layout & accessibility
- **Vanilla CSS**: Custom animations, responsive grid & flexbox, glassmorphism, halftone textures
- **Vanilla JavaScript**: Particle canvas engine, 3D card tilt physics, scroll-triggered reveals
- **Hosting**: Vercel

## 💻 Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muditkumawat21-hue/Mudit-Portfolio.git
   cd Mudit-Portfolio
   ```

2. **Open in browser:**
   ```bash
   open index.html
   ```
   Or use a local development server like Live Server or `npx serve`.
